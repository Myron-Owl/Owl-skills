# 润笔 · runbi

版本：0.2.0

用于中文文章、日记、随笔、读后感、回答和照片配文的润色。减少空话、重复和机械表达，保留原意、立场、文体与作者声音。支持参考流离色的个人文风。

## 使用

安装到 Codex 后用 `$runbi`，在 Claude Code 中可用 `/runbi`，并提供待改文字。例如：

> 用 $runbi 润色下面这段，保留我的原意和语气，减少空话与机械表达。

也可以说明“轻润”“保留随笔感”“保持正式公告文体”或“只诊断不改稿”。没有合适的修改理由时，可以保留原句。

## 编辑原则

- 清理无用铺垫、重复总结和助手式外壳，保留有效的过渡、情绪、引文和礼貌。
- 把原有动作说清楚，稳定术语和指代，保留文学性称呼、正式别名及专业术语。
- 检查空转句式和段落套路，按内容安排详略；不规定句长、段长、删字比例或固定禁词。
- 优先解释具体事实、机制和过程，检查防御性否定、假想反方和虚假对立。该规则适用于所有自然语言，未经请求的澄清默认零次，确有必要时整篇最多一次。
- 保留数字范围、时间、条件、归因、确定程度和完成状态，不编造经历、感受、数据或结论。
- 先核对原意，再通读语气和节奏；不靠检测器分数验收，不判断文章是否由 AI 生成。

## 个人风格参考

这是包含流离色个人文风参考的自用版本。参考来自作者提供的文字语料，包含近年日记与早年作品；使用时先尊重当前稿件和本次要求，再按文体参考生活细节、自然转折、自嘲、联想及抒情节奏。

其他作者复用时，应提供自己的样本并替换或明确停用个人参考，避免套用他人的口吻。原始文集不随技能发布，技能仅保留必要的短摘句和来源边界。知乎回答及照片配文尚无充分的独立样本验证。
