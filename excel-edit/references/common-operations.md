# Common native operations

Add optional lists to the normal plan; no custom save script. Existing cell values/formulas still use operations. operations=[] is allowed for format/rule-only plans. Source formats are copied before content/color operations; colors subsequently requested in operations take precedence.

format_copies items have exactly sheet, range, source_sheet, source_range. Same-size unmerged rectangles, at most 256 cells per copy, no overlapping destinations, protected target or conditional formatting. Example: {"sheet":"Data","range":"H9","source_sheet":"Data","source_range":"H8"}. This explicitly copies the cell's complete formatting, never contents, dimensions, validation or merges. For color-only requests use the existing color operations. Choose a same-kind source; don't infer permission to copy an entire style from a color request.

validations items have exactly sheet, cell, before, after. Read before using native_operations.signature(native_operations.rule_at(wb[sheet],cell)); null means no rule. after accepts DataValidation fields: type (whole/decimal/custom), operator, formula1, formula2, allowBlank, showErrorMessage, showInputMessage, errorTitle, error, promptTitle, prompt, errorStyle. Example after: {"type":"decimal","operator":"greaterThan","formula1":"0","allowBlank":false,"showErrorMessage":true}. Custom formulas use Excel syntax. Omitted fields use DataValidation defaults, so copy requested prompt/error properties deliberately.

One unmerged cell per rule edit; duplicate or overlapping rules are rejected. Splitting a shared whole/decimal rule with constant numeric bounds preserves its remaining cells. Shared relative formulas, lists, conditional formatting and large validation maps need scoped handling rather than guessed formula rebasing. Effective rules are compared after reopening, including unaffected cells. Unknown changes cannot be hidden by deleting a whole shared validation rule.

For unsupported local format/rule extensions, execute(plan, extension) accepts an object with prepare(wb,plan), apply(native_workbook,plan), verify_native(native_workbook,plan). prepare declares expected format/rule changes in the inspection workbook; it must preserve contents, formulas, sheets, dimensions and merges. apply performs exactly those changes; verify_native checks any extra native semantics. The executor captures expected styles/metadata after prepare, restores only proven untouched merged-wrap loss, and verifies before committing. Existing contents are edited through plan operations. This interface is bounded to 20,000 loaded cells; it is not a structural editing API. Never save through openpyxl, replace originals, or independently own Excel sessions from an extension.
