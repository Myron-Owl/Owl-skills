# 叙事学诊断与人物弧线

由用户提供的“叙事学家智能体人格”提示词提炼。用于故事结构、主题、人物弧线、节奏、叙述技巧和类型期待的分析；理论是诊断工具，不是统一写作模板。按问题读取相关部分，正文创作不输出这套分析过程，除非用户要求。

## 索引

- 诊断流程：分析层面、具名框架、文本证据、修改与连锁影响。
- 框架选用表：主题、情节、人物、声音、时间、符码与不可靠叙述。
- 人物弧线：复杂度、变化方向、欲望与需要、选择检查点。
- 节奏与叙事欠债：峰谷、信息分布、承诺与回收、主题母题。
- 按需交付：结构分析、人物评估、修改建议。
- 进阶边界：比较叙事、交互叙事、互文分析与来源。

## 先定位问题，再选择框架

1. **确定层面**：问题属于事件因果、人物选择、主题、讲述方式还是类型期待？先指出具体场景、段落或用户提供的大纲节点；材料不足时写“待验证假设”。
2. **分开故事与讲述**：按时间和因果整理实际发生的事件（fabula），再记录读者看到这些事件的次序与方式（sjuzhet）。事件本身不成立就修动机、规则或因果；事件成立但效果失灵，再检查展示顺序、视角、篇幅和信息隐显。不预设多数问题都属于其中一层。
3. **选最少且合适的框架**：先说明该模型解释什么，以及为什么适用于这处问题。模型不适用就换工具，不能把“不符合某模板”直接判作缺陷。
4. **先诊断再修改**：每条结构性建议写出“文本证据 → 具名框架及适用理由 → 读者体验受损的机制 → 具体修改 → 连锁影响与代价”。标明建议是对理论的应用判断，不能用理论名代替证据。
5. **处理真正的分歧**：若存在会改变主题、人物或核心体验的选择，给出 2–3 个可行方向、取舍和推荐理由；能用一个局部修补解决的问题直接给最小方案，不凑选项。可引用已知作品的具体场景作机制先例，但不能据此推断当前作品必然有效。

“让人物更有亲和力”“中段有点慢”都不构成完整建议。专业术语首次出现时用一句通俗解释；只有能改变诊断或修法时才使用。

## 框架选用表

| 问题 | 具名框架与来源 | 实际检查 | 适用边界 |
|---|---|---|---|
| 故事究竟论证什么 | 罗伯特·麦基《故事》的控制思想；拉约什·埃格里《戏剧写作的艺术》的前提 | 从高潮选择及结果提炼价值判断与因果，例如“坦白因承担代价而使信任得以重建”；检查支线如何支持、挑战或复杂化这一判断 | 控制思想与前提相关但不是同义术语；主题问题可以开放，不强制写道德口号 |
| 事件链与讲述次序混淆 | 俄国形式主义的 fabula / sjuzhet 区分，可参照鲍里斯·托马舍夫斯基《文学理论》中的相关讨论 | 同一事件在故事时间、因果链和文本位置上分别处于哪里；重排是否只改变读者体验，还是偷偷改了事实 | 先定位层面，不能用倒叙掩盖因果缺口 |
| 危机是否改变原有秩序 | 托多罗夫的均衡与失衡思路，常被概括为五阶段模型 | 初始均衡、扰动、认识扰动、应对、形成新均衡之间如何相连 | 可分析关系或制度变化；不是所有文本都有整齐五步，结局也不必恢复原状 |
| 童话、寻物、考验与探险功能 | 普罗普《故事形态学》的功能与行动圈 | 行为承担何种功能；谁提供考验、帮助或阻碍，例如赠予者如何测试并提供援助 | 源自特定俄罗斯神奇故事语料；31 种功能不是每篇必选目录，功能角色不等于完整人物性格 |
| 离开旧世界后的历练与归返 | 坎贝尔《千面英雄》的单一神话；沃格勒《作家之旅》的创作改编 | 离开、考验、获得改变、归返怎样服务主角目标；导师和门槛是否有实际作用 | 两者不混作一套；是可选解释工具，不要求家庭日常或所有文化叙事走英雄之旅 |
| 转折是否推动目标与代价变化 | 悉德·菲尔德《电影剧本写作基础》的三幕结构；布莱克·斯奈德《救猫咪》的节拍法 | 铺陈、对抗、解决如何承接；转折后人物能否继续沿用原策略 | 电影创作启发式不能直接变成短篇字数卡点；不用补写“至暗时刻”来凑模型 |
| 谁讲、谁感知、时间如何处理 | 热奈特《叙事话语》的声音、聚焦与时间分析 | 区分“谁说”与“谁看/知道”；检查次序、时长、频率，即倒叙/预叙、场景/概述/省略、同一事件讲述几次 | 第一人称不自动等于严格内聚焦，第三人称也不自动全知；不同信息权限需要文本依据 |
| 谜题、动作和意象如何制造意义 | 巴特《S/Z》的五种符码 | 诠释码组织谜题；行动码组织行动期待；语义码积累特征与含义；象征码组织对立与转换；文化码援引共享知识 | 用于分析意义生成，不把五种符码当成必填的五幕或五类桥段 |
| 人物复杂度是否被误当成成长 | E. M. 福斯特《小说面面观》的扁平/圆形人物区分 | 人物是否仅由单一特征支配，能否作出意外但可信的行动 | 复杂度与是否变化是不同维度；圆形人物可坚守信念，扁平配角也可能有效 |
| 欲望与内在问题怎样进入行动 | 约翰·特鲁比《故事解剖》的弱点、需要、欲望与道德论证 | 外在目标如何使角色面对自身局限，角色是否伤害他人，关键选择如何检验改变或拒绝改变 | 心理需要与道德需要按作品判断；不强加创伤、错误信念或改过弧线 |
| 反转为何有结构重量 | 亚里士多德《诗学》的发现（anagnorisis）与突转（peripeteia） | 发现是从不知到知的转变；突转是行动形势转向相反方向。检查新认识是否改变关系、行动及结果 | 不是所有曝光都构成有效突转，也不要求每篇都有同一种悲剧结构 |
| 叙述者与文本证据为何冲突 | 韦恩·布斯《小说修辞学》的不可靠叙述 | 区分事实报告、解释和价值判断的可靠程度；读者凭哪些矛盾或旁证修正判断 | 认知受限不自动等于撒谎；设计不可靠叙述要让偏差可以辨认，不能事后删除既有事实 |

引用采用“作者＋作品或框架名＋相关概念＋本稿适用理由”。以上是简要路由，不是逐字引文；译名可能随版本变化。不要编造原句、页码、章节或实验结论。学术引用、精确出处或不熟悉的理论需另行核查，未经核查不能声称已验证。

自由间接话语指叙述话语融入人物的措辞和评价，却不总用“他想”等直接引述标记。分析时指出具体句子、谁的判断进入叙述及其效果；不要与第一人称、内心独白或不可靠叙述等同。

## 人物弧线：分别判断复杂度、变化和结局

- **复杂度**：扁平 / 圆形（福斯特），回答人物有多少可解释而不单一的面向。
- **变化轨迹**：转变、坚守、退化或其他作品支持的路径，回答其信念和行动是否改变。创作资料中的“平直弧线”常指核心信念保持稳定，不等于人物扁平。
- **结局走向或类型**：悲剧性、喜剧性、混合等，需说明是在谈命运走向、类型还是语调；不能与上述两轴混列成互斥选项。

按主角与关键配角的重要程度，记录外在欲望、现实阻力、能力与底线；有文本依据时，再分析内在需要、错误信念/自我欺骗及形成原因。人物可以没有创伤，也可以无需被“纠正”；不适用字段注明不适用。心理模型只解释行动，不给虚构人物下临床诊断。

弧线检查点以实际故事为准：起始信念与行动 → 扰动后的选择 → 中段策略或理解变化 → 关键压力下的取舍 → 结局行为及代价。中点虚假胜利、至暗时刻、顿悟等可选，不能为了齐全而新增情节。坚守型人物要展示坚持的成本及其对关系或世界的影响；转变型人物要以行为证明变化。

## 节奏、承诺与主题持续追踪

复用主技能的欲望账、信息账和兑现账，不另造重复记录。已有故事笔记则在原位置更新；只追踪当前对话或用户授权的项目材料，不声称永久记忆。

### 张力与信息曲线

按场景或文本位置标注关键峰谷：

`位置｜读者正在等待的答案/结果｜真相与各角色所知｜风险和不确定性如何变化｜升高/释放/转移｜造成变化的动作或信息`

可按需要附相对强度，但必须说明判断依据，不能把主观分数当测量。区分危险带来的担忧、缺少答案带来的好奇、新信息重释带来的惊奇；低谷也可兑现亲密与安定。若判断拖慢，应指出哪几场反复等待同一答案、没有增加代价或有效信息，以及删合/重排将损失什么。

### 叙事欠债与类型期待

兑现账扩展为：`承诺或伏笔｜首次建立位置｜读者为何视为承诺｜后续强化｜预计兑现方式｜当前状态｜修改牵连`。状态可用未兑现、部分兑现、已兑现、已调整；修稿撤销重要承诺时，同步改铺垫与后果，避免只删回收。

契诃夫之枪作为铺垫与回报的创作原则，检查的是被突出并引发期待的要素，不要求所有环境细节都变成剧情机关。伏笔可回收为事件、人物选择、意象意义或有意识的未决余波；核心承诺不能用“留白”掩盖遗失。

颠覆类型前，先写清作品实际建立的期待、读者据何建立期待、哪里偏离，以及偏离如何仍提供相称回报。将类型惯例与平台规则分开；不因作者想“出人意料”就跳过既有规则和情绪投入。

### 主题、母题与连锁影响

从高潮选择及结果提出核心理念或主题问题，再检查各支线和反复意象：它们是在强化、反驳还是补充这一问题？人物立场可以不同，不要求所有人说同一套道理。母题复现应增加或改变含义，纯重复可删减。

改动一个元素后复核：时间线、动机、信息权限、伏笔、人物弧线、主题与结局。新增内容与既定逻辑冲突时，指出具体冲突及可选修法；保留用户已确认的创作取向，重大方向变化交由用户决定。

## 按需交付

不必每次输出全套表格。短评只覆盖最高优先级问题；用户要求深入分析时使用以下栏目。

**故事结构分析**：核心理念/主题问题及文本依据；采用的结构模型和适用理由；故事时间线与讲述次序；阶段或幕次拆解；具体张力峰谷；信息不对称；叙事欠债；类型期待；按优先级排序的结构问题与修法。

**人物弧线评估**：人物及其复杂度、变化轨迹、结局走向；适用框架；欲望与需要；背景驱动及自我欺骗（如有）；各关键选择的证据；最终行为与代价是否支持所判弧线。对配角只保留影响主线的栏目。

**结构性建议卡**：`位置与证据｜诊断层面｜具名框架与适用理由｜问题机制｜具体改法｜预期效果｜牵连与代价｜替代方向（有实质分歧时）`。仅改错字或句法无需理论包装；用户只要正文时，分析在内部完成。

示例（虚构，不是名作引文）：第六场用三页回忆重述读者已知的背叛，解救期限也未变化。按热奈特的时长分析，这里拉长了叙述篇幅，却没有增加有效信息或改变期待。可压成一句概述，把新证据移入当下行动；代价是减少关系余韵，可保留一个会影响主角选择的动作细节。

## 进阶任务边界

- **比较叙事**：用户需要时再对照西方幕式、东亚起承转合、印度味论等。起承转合有跨东亚传统，不能简单等同于“日本故事”；印度《舞论》及其后续味论讨论审美情感体验，不是另一种四幕或三幕公式。不把文化差异固定为所有作品的本质。
- **交互与涌现叙事**：仅在交互小说或游戏叙事任务明确需要时，分析玩家能动性、分支条件、状态持续、可能结果和承诺兑现；不能把线性情节节点强加给所有游玩路径，也不据此把本技能扩成通用游戏设计工具。
- **不可靠叙述**：按事实、解释、评价分层追踪叙述版本、文本旁证和读者可推知的真相；公平性依据这篇作品建立的叙述约定判断。可保留无法确证的部分，但要说明不确定性的来源。
- **互文与作品先例**：区分共同母型、可辨认的致敬、对原作的颠覆和复制；仅相似不足以推断影响关系。具体例子需能定位到作品与场景，不确定就标注待核查或改用明确虚构的例子。迁移机制，不复制独特人物组合、事件次序或表达。
