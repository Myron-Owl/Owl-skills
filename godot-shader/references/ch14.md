# 第 14 章：用遮罩驱动角色特效

### 第 14 章：用遮罩驱动角色特效
**学习目标**：掌握用噪声 + 阈值建立遮罩的技术，理解同一套 noise → threshold → mask 公式通过控制不同的输出目标（透明度 / 纹理 / 颜色），可以派生出溶解消散、隐身斗篷和扫描线透视三种完全不同的角色特效。

**场景搭建**：本章三个实战共享同一场景基础——创建一个 Sprite2D 节点（挂角色纹理），为其新建 ShaderMaterial，选择 canvas_item 类型。它们都需要一个额外的 NoiseTexture2D 资源。隐身斗篷需置于一个有实际背景的场景中，因为它的效果依赖于读取 SCREEN_TEXTURE 获取背景画面。

**内容要点**：

- 遮罩驱动的通用公式：noise → threshold → mask，然后分支——控制 alpha（溶解）、控制纹理（斗篷）、控制颜色（扫描线）
- 溶解核心公式：smoothstep(dissolve_amount, dissolve_amount + edge_width, noise) 产生遮罩 → 控制 COLOR.a
- 边缘发光公式：双 smoothstep 交集 edge = s1 * (1 - s2) 掐出窄环 → mix(tex_color, edge_color, edge)
- 隐身斗篷：同样 noise + smoothstep 建立遮罩，但遮罩区域的输出不是 alpha=0，而是 SCREEN_TEXTURE——"不是变透明，是换纹理"
- 隐身斗篷的噪声偏移：对 SCREEN_TEXTURE 的采样 UV 加躁波偏移模拟光线弯曲
- 扫描线偏振：mask 来源不是噪声纹理，而是 UV.y + TIME 生成的移动光带——噪声在其中制造不规则断裂
- 扫描线的颜色变换：mask 区域内转为灰度 + 叠加扫描色 + 强发光，mask 区域外保持原图

## 14.1 溶解效果

### 14.1.1 为什么需要溶解
游戏中角色死亡后直接消失——"噗"一声，角色瞬间变透明——这种处理方式很廉价。想象一个法师释放火球术：火球命中敌人时，敌人不是整块消失，而是从中心开始崩解成碎片，边缘还带着烧焦的橘红色……

这就是**溶解效果（dissolve effect）**：用噪声纹理定义每个像素的"抵抗力"，然后用一个外部驱动的阈值逐像素决定哪些区域先消失、哪些后消失。

溶解解决的三个问题：
1. **控制消失顺序**：不是所有像素同时消失——噪声值低的像素先走，高的后走，形成自然的不规则边缘
2. **制造燃烧/消融边缘**：在"正在消失"与"还未消失"的分界线上加一层发光——模拟火焰烧灼或魔法能量
3. **与游戏逻辑联动**：GDScript 的 Tween 可以用于驱动 dissolve_amount 从 0 匀速变化到 1

下面用几个步骤渐进构建这个效果。

### 14.1.2 第 1 步：step()——硬边消失
编写并挂载如下的shader代码，并给dissolve_texture设置noise材质。这里的关键是使用了step函数。

**step() 解决了一个问题：把一个连续值（噪声）一刀切成"0 或 1"。**

step(edge, x) 的规则：x < edge → 返回 0，x >= edge → 返回 1。

把噪声值当成 x，把外部控制的阈值当成 edge：噪声值低于阈值的像素返回 0（消失），高于阈值的返回 1（保留）。

```
shader_type canvas_item;

uniform float dissolve_amount : hint_range(0.0, 1.0) = 0.3;
uniform sampler2D dissolve_texture ;

void fragment() {
    vec4 tex_color = texture(TEXTURE, UV);
    float noise = texture(dissolve_texture, UV).r;

    float mask = step(dissolve_amount, noise);

    COLOR = tex_color;
    COLOR.a = tex_color.a * mask;
}
```
**效果**：噪声纹理中每个像素的 R 通道值在 [0, 1] 之间随机分布，低值区和白值区自然交替。当 dissolve_amount 从 0 扫到 1 时，低值像素先被"吃掉"，高值像素最后才消失——视觉上产生**碎片从多到少、逐步崩解**的自然效果。

### 14.1.3 第 2 步：smoothstep()——软边过渡
**smoothstep() 解决了 step() 的"一刀切"问题：它在一小段区间内做平滑过渡，而不是在某个点上突然跳变。**

smoothstep(edge0, edge1, x) 的规则：
- x <= edge0 → 返回 0
- x >= edge1 → 返回 1
- 中间 → Hermite 曲线 3t² − 2t³ 平滑过渡

把第 1 步的 step(dissolve_amount, noise) 换成 smoothstep(dissolve_amount, dissolve_amount + softness, noise)，给溶解边缘一个平滑的过渡区间：

```
uniform float edge_width : hint_range(0.0, 0.2) = 0.05;

void fragment() {
    vec4 tex_color = texture(TEXTURE, UV);
    float noise = texture(dissolve_texture, UV).r;
    float alpha = smoothstep(dissolve_amount, dissolve_amount + edge_width, noise);
    COLOR = tex_color;
    COLOR.a = tex_color.a * alpha;
}
```
**效果**：边缘不再像剪刀剪过——从"完全保留"到"完全消失"之间有了一段渐变。edge_width 越大，过渡越柔和。但此时只有半透明渐变，没有任何颜色变化——纯粹是 alpha 在降。

### 14.1.4 第 3 步：边缘发光——让溶解"烧起来"
目前还缺少最关键的一环：**正在消失的边缘应该有颜色变化**——模拟烧焦的橘红、魔法能量的蓝色，或是腐蚀的绿色。边缘发光解决了一个问题：怎么精确找到"正在溶解的那一圈像素"？

答案是在阈值两侧各画一条 smoothstep 线，两条线之间的区域就是边缘：

```
float edge = smoothstep(dissolve_amount, dissolve_amount + edge_width*0.5, noise);
edge *= 1.0 - smoothstep(dissolve_amount + edge_width*0.5, dissolve_amount + edge_width, noise);
```
我们要制造一个类似小山坡的横截面，第一条 smoothstep在溶解线左侧产生从 0 到 1 的升起。第二条 1.0 - smoothstep在右侧产生从 1 到 0 的下降。整个宽度是edge_width的大小。两个函数相乘后，中间交叠的区域 ≈ 1，两侧 ≈ 0，形成一条**窄环**，正好位于在溶解边界上。然后用 mix() 把这条窄环染成边缘发光色：

```
uniform vec4 edge_color : source_color = vec4(1.0, 0.5, 0.0, 1.0);

void fragment() {
    vec4 tex_color = texture(TEXTURE, UV);
    float noise = texture(dissolve_texture, UV).r;
    float dissolve_edge = dissolve_amount + edge_width;
    float alpha = smoothstep(dissolve_amount, dissolve_edge, noise);
    float edge = smoothstep(dissolve_amount, dissolve_amount + edge_width*0.5, noise);
    edge *= 1.0 - smoothstep(dissolve_amount + edge_width * 0.5, dissolve_edge, noise);
    COLOR = mix(tex_color, edge_color, edge);
    COLOR.a = tex_color.a * alpha;
}   
```
**效果**：溶解边缘燃烧着橘红色的光，edge_width 控制光环宽度，edge_color 控制发光颜色。换绿色 = 腐蚀酸液，换蓝色 = 魔法分解，换白色 = 光化消失。

## 14.2 隐身效果

### 14.2.1 溶解的局限：透明 ≠ 隐身
第 14.1 节的溶解效果做到了"角色逐渐消失"——噪声值低的像素 alpha → 0，高的保留。这在死亡/分解场景中完全够用。

但有一种效果，变透明做不出来：**隐身斗篷（stealth cloak / active camouflage）**。想象一个装备光学迷彩的角色站在丛林前——她不是变透明，而是"她所在的位置显示的是丛林背景"。光线似乎穿过了她的身体。

**隐身斗篷和溶解的区别**：

| 维度 | 溶解 | 隐身斗篷 |
| 消失区域的显示 | alpha = 0（透明） | 显示 SCREEN_TEXTURE（背景画面） |
| 视觉效果 | 碎片飞散消失 | 角色"融入"环境 |
| 核心技术 | noise + smoothstep → COLOR.a | noise + smoothstep → mix(background, visible, mask) |
| COLOR.a 的处理 | 随溶解进度递减 | 不变 |
| 适用场景 | 死亡/消失/分解 | 潜行/隐身/光学迷彩 |

两者共用同一个核心技术：**噪声纹理 + smoothstep 建立遮罩**。但后续操作完全不同——溶解改 alpha，斗篷换纹理且**从不改 alpha**。这就是本章把两者放在一起教的原因：**同一套 noise → threshold → mask，换一个输出目标，就是两种完全不同的效果**。

### 14.2.2 第 1 步：用 mask 切换角色与背景
和溶解一样，从噪声采样开始。但这一次，遮罩的作用不是控制 alpha，而是控制 **mix() 的混合权重**——决定像素输出角色原色还是背景画面：

```
shader_type canvas_item;

uniform sampler2D screen_texture : hint_screen_texture;
uniform sampler2D noise_texture : repeat_enable;
uniform float cloak_amount : hint_range(0.0, 1.0) = 0.5;
uniform float edge_width : hint_range(0.001, 0.2) = 0.05;

void fragment() {
    vec4 original = texture(TEXTURE, UV);
    float noise = texture(noise_texture, UV).r;
    float mask = smoothstep(cloak_amount, cloak_amount + edge_width, noise);
    vec4 background = texture(screen_texture, SCREEN_UV);

    COLOR = mix(background, original, mask);
    COLOR.a = original.a;
}
```
**关键变化**：

- mask = smoothstep(...)——噪声值高的像素 mask → 1（可见），噪声值低的像素 mask → 0（斗篷覆盖区）。这和溶解的 alpha 方向**相反**——溶解中 smoothstep 结果赋给 alpha（低值 = 消失），这里 mask=0 赋给背景切换。
- mix(background, original, mask)——当 mask=0（斗篷区域），输出背景；当 mask=1（可见区域），输出角色原色。
- COLOR.a = original.a——**alpha 从未被修改**。角色在可见区域保留原始透明度，在斗篷区域直接显示背景像素（背景像素本身是不透明的）。
**认知锚点**：溶解是"这个像素变透明了"（alpha=0）。斗篷是"这个像素不存在了——请画背景"（mix 到背景）。前者需要场景支持透明混合（blend_mix），后者在任何混合模式下都能工作。

### 14.2.3 第 2 步：边缘发光——让边界可见
完全融入背景的斗篷太完美了——玩家看不到任何反馈。给 mask 的过渡区域内加一圈淡色轮廓：

```
float edge = smoothstep(cloak_amount, cloak_amount + edge_width * 0.5, noise);
edge *= 1.0 - smoothstep(cloak_amount + edge_width * 0.5, cloak_amount + edge_width, noise);
```
这段代码和溶解的第 3 步完全相同——双 smoothstep 构造出一个窄环。用这个 edge 值给可见区域的像素掺入发光色：

```
uniform vec4 edge_color : source_color = vec4(0.4, 0.8, 1.0, 1.0);

vec4 visible = mix(original, edge_color, edge);
COLOR = mix(background, visible, mask);
```
**效果**：在斗篷与可见区域的交界处，可见侧（mask → 1）的像素逐渐染上淡蓝光。这给玩家一个"这里有东西"的视觉提示——看得见光，但看不清人。

**理解 mask 的分层角色**：mask 在 0→1 之间有三层含义——mask=0（斗篷深处：纯背景）、mask≈0.5（边界：edge 最强，背景与边缘光混合）、mask=1（可见：角色原色，edge=0）。这三层通过一个 mix(background, visible, mask) 串在一起。

### 14.2.4 第 3 步：背景扭曲——模拟光线弯曲
光学迷彩不是完美的镜面。光线穿过斗篷时会被轻微扰乱。通过偏移 SCREEN_TEXTURE 的采样 UV 来模拟：

```
uniform float distortion_strength : hint_range(0.0, 0.05) = 0.015;
uniform float distortion_speed = 0.5;

vec2 offset = texture(noise_texture, UV * 3.0 + TIME * distortion_speed).rg;
offset = (offset - 0.5) * distortion_strength;

vec4 background = texture(screen_texture, SCREEN_UV + offset);
```
(offset - 0.5) 把 noise 的 [0,1] 范围中心化到 [-0.5, 0.5]，再乘以 distortion_strength 控制偏移幅度。SCREEN_UV + offset 让背景在斗篷区域产生扭曲——和热浪折射是同一种手法，但这里偏移量更微小，只产生"光线轻微弯曲"的细微失真。

注意 UV * 3.0 + TIME * distortion_speed——噪声采样的 UV 被放大 3 倍（纹理频率更高），且随时间流动。这意味着扭曲是不停变化的，像流动的流水。

### 14.2.5 第 4 步：背景染色——给斗篷一个"颜色个性"
给背景画面叠加一层淡色调，让斗篷看起来像一种"能量场"：

```
uniform vec4 cloak_tint : source_color = vec4(0.5, 0.9, 1.0, 1.0);
uniform float tint_strength : hint_range(0.0, 1.0) = 0.25;

background.rgb = mix(background.rgb, cloak_tint.rgb, tint_strength);
```
tint_strength = 0 → 纯背景（完全透明），tint_strength = 1 → 彻底染色。推荐 0.2–0.4——刚好让玩家察觉"这里有个隐形角色"，但不足以辨认细节。

### 14.2.6 第 5 步：组装成品
把所有步骤整合：

```
shader_type canvas_item;

uniform sampler2D screen_texture : hint_screen_texture;
uniform sampler2D noise_texture : repeat_enable;
uniform float cloak_amount : hint_range(0.0, 1.0) = 0.5;
uniform float edge_width : hint_range(0.001, 0.2) = 0.05;
uniform float distortion_strength : hint_range(0.0, 0.05) = 0.015;
uniform float distortion_speed = 0.5;
uniform vec4 edge_color : source_color = vec4(0.4, 0.8, 1.0, 1.0);
uniform vec4 cloak_tint : source_color = vec4(0.5, 0.9, 1.0, 1.0);
uniform float tint_strength : hint_range(0.0, 1.0) = 0.25;

void fragment() {
    vec4 original = texture(TEXTURE, UV);
    float noise = texture(noise_texture, UV).r;
    float mask = smoothstep(cloak_amount, cloak_amount + edge_width, noise);
    float edge = smoothstep(cloak_amount, cloak_amount + edge_width * 0.5, noise);
    edge *= 1.0 - smoothstep(cloak_amount + edge_width * 0.5, cloak_amount + edge_width, noise);
    vec2 offset = texture(noise_texture, UV * 3.0 + TIME * distortion_speed).rg;
    offset = (offset - 0.5) * distortion_strength;
    vec4 background = texture(screen_texture, SCREEN_UV + offset);
    background.rgb = mix(background.rgb, cloak_tint.rgb, tint_strength);
    vec4 visible = mix(original, edge_color, edge);

    COLOR = mix(background, visible, mask);
    COLOR.a = original.a;
}
```

## 14.3 扫描线效果

### 14.3.1 第三种遮罩来源
溶解和斗篷的遮罩都来自噪声纹理——texture(noise_texture, UV).r + smoothstep 建立 mask。但遮罩的来源不止这一种。

**扫描线偏振（scanner effect）**的遮罩来自 UV 坐标本身：一条沿 Y 轴匀速移动的水平光带。当光带扫过某个像素时，该像素进入"扫描模式"——换颜色、加辉光。光带离开后，像素恢复正常。

这说明了一个重要事实：mask 的来源可以是任何产生 [0, 1] 连续值的东西。噪声纹理是一种来源。UV + 时间 + smoothstep 是另一种。两张不同的 mask 纹理 mix() 是第三种。遮罩管线 noise → threshold → mask 中的第一项"noise"可以替换为任何连续信号。

### 14.3.2 第 1 步：一个静止的水平光带
用 UV.y 和 smoothstep 造一条带：

```
shader_type canvas_item;

uniform float scan_width = 0.15;

void fragment() {
    vec4 tex = texture(TEXTURE, UV);
    float scan_y = 0.5;
    float scan = 1.0 - smoothstep(0.0, scan_width, abs(UV.y - scan_y));

    COLOR.rgb = mix(tex.rgb, vec3(0.2, 0.9, 1.0), scan);
    COLOR.a = tex.a;
}
```
**abs(UV.y - scan_y)** 计算当前像素到扫描线中心的垂直距离。当 UV.y = scan_y 时距离为 0，1.0 - smoothstep(0.0, scan_width, 0.0) = 1.0——扫描线中心返回 1。当 |UV.y - scan_y| > scan_width 时，smoothstep 返回 1，1.0 - 1.0 = 0.0——光带外返回 0。

结果：一条位于屏幕正中央（y=0.5）、宽度为 scan_width 的水平青色光带。光带内显示青色，光带外显示原图。

### 14.3.3 第 2 步：让光带动起来
用 fract(TIME * speed) 驱动扫描线的 Y 坐标，产生周而复始的上下扫描：

```
uniform float scan_speed = 0.3;

float scan_y = fract(TIME * scan_speed);
float scan = 1.0 - smoothstep(0.0, scan_width, abs(UV.y - scan_y));
```
fract() 取小数部分——当 TIME * speed 超过 1.0 时自动回到 0.0，让扫描线从屏幕顶部循环到底部。保存后你会看到一条光带从上到下匀速扫描，周而复始。

### 14.3.4 第 3 步：噪声制造不规则断裂
匀速平滑的扫描线太"完美"了。真正的扫描器会有信号干扰——光带在某些区域断裂、变暗。用噪声纹理调制扫描线强度：

```
uniform sampler2D noise_texture : repeat_enable;
uniform float noise_strength = 0.5;

float noise = texture(noise_texture, UV * 6.0 + TIME).r;
scan *= mix(1.0 - noise_strength, 1.0, noise);
```
当 noise → 1（噪声高值区），mix(0.5, 1.0, 1.0) = 1.0，scan 不变（光带完整）。当 noise → 0（噪声低值区），mix(0.5, 1.0, 0.0) = 0.5，scan 减半（光带变暗/断裂）。

UV * 6.0 将噪声纹理在扫描区域内平铺 6 次（更高密度）。+ TIME 让噪声随时间流动——断裂的位置不断变化，而不是固定在某个区域。

### 14.3.5 第 4 步：灰度 + 扫描色 + 强发光
光带扫过的区域不应该只是纯色覆盖——扫描器的经典视觉是"看到部分内部结构"：灰度轮廓 + 扫描色叠加 + 边缘强辉光。

```
uniform vec4 scan_color : source_color = vec4(0.2, 0.9, 1.0, 1.0);
uniform float glow_strength = 2.0;

float gray = dot(tex.rgb, vec3(0.299, 0.587, 0.114));
vec3 xray = mix(vec3(gray), scan_color.rgb, 0.8);
xray += scan_color.rgb * scan * glow_strength;

COLOR.rgb = mix(tex.rgb, xray, scan);
COLOR.a = tex.a;
```
逐行解释：

- gray：亮度加权灰度（同第 6 章——人眼对绿色最敏感，权重 0.587）
- xray = mix(vec3(gray), scan_color.rgb, 0.8)：80% 扫描色 + 20% 灰度——"带颜色的透视"，保留物体轮廓
- xray += scan_color.rgb * scan * glow_strength：在扫描线中心（scan → 1），额外叠加辉光
- mix(tex.rgb, xray, scan)：光带内显示 X 光效果，光带外保持原图

### 14.3.6 第 5 步：组装成品

```
shader_type canvas_item;

uniform vec4 scan_color : source_color = vec4(0.2, 0.9, 1.0, 1.0);
uniform float scan_width = 0.15;
uniform float scan_speed = 0.3;
uniform float glow_strength = 2.0;
uniform sampler2D noise_texture : repeat_enable;
uniform float noise_strength = 0.5;

void fragment() {
    vec4 tex = texture(TEXTURE, UV);
    float scan_y = fract(TIME * scan_speed);
    float scan = 1.0 - smoothstep(0.0, scan_width, abs(UV.y - scan_y));
    float noise = texture(noise_texture, UV * 6.0 + TIME).r;
    scan *= mix(1.0 - noise_strength, 1.0, noise);

    float gray = dot(tex.rgb, vec3(0.299, 0.587, 0.114));
    vec3 xray = mix(vec3(gray), scan_color.rgb, 0.8);
    xray += scan_color.rgb * scan * glow_strength;

    COLOR.rgb = mix(tex.rgb, xray, scan);
    COLOR.a = tex.a;
}
```

### 本章小结：遮罩模式一览
本章三个效果全部基于同一套 noise → threshold → mask 管线。把它们并排对比，能看到模式如何演化：

| 步骤 | 溶解 | 隐身斗篷 | 扫描线 |
| 1. 遮罩来源 | noise 纹理 + smoothstep | noise 纹理 + smoothstep | UV.y + TIME + smoothstep + noise |
| 2. mask 方向 | mask → 1 = 保留 | mask → 1 = 可见 | scan → 1 = 扫描区 |
| 3. mask 控制什么 | COLOR.a | mix(background, visible, mask) | mix(tex.rgb, xray.rgb, scan) |
| 4. 边缘处理 | mix(原色, 发光色, edge) | mix(原色, 发光色, edge) | += 扫描色 * scan * glow |
| 5. alpha 处理 | 随 mask 递减 | 不变 | 不变 |

核心规律：**遮罩控制"哪些像素受影响"，后续 mix/multiply/add 控制"受影响像素做什么"**。把这两层解耦，换任何一个维度，就是一个全新的效果。
