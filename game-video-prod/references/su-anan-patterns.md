# 苏安安游戏推荐：可迁移模式

## 使用范围

本页用于 B 站“发现新游戏、快速判断是否想玩”的推荐视频，尤其适合模拟经营、种田、生存、建造与休闲独游。它不是人格模仿模板。保留频道自己的策划视角、用词和判断，只借鉴信息组织、镜头兑现和包装层级。

当用户明确要求参考苏安安，或要做 B 站发现型推荐、月度盘点、促销选购时读本页。做长篇机制评测时只使用“开场兑现、口语压缩、封面层级”三项，不要把整篇改成快节奏安利。

## 一、文稿：先卖玩家幻想，再解释系统

### 发现型开场

单游戏推荐的前 15–20 秒优先按以下顺序组织：

1. **0–3 秒：一句玩家幻想。** 用“真宝藏”“家里有矿”这类结论时，画面必须立刻展示对应的稀有动作或结果。
2. **3–12 秒：3–5 个动作短句。** 每句只写一个动作与一个对象，例如“打磨宝石”“卖给客人”“赌石翻身”“装扮小窝”。
3. **12–20 秒：矛盾或代价。** 补上失败风险、重复压力、价格门槛或“好缝但还想玩”的反差，避免纯夸。
4. **20 秒后：报游戏名与判断框架。** 说明接下来会验证什么，不重复片头口号。

月度盘点的前 20–25 秒改用：`垂类身份句 → 本期覆盖范围 → 数量/平台/栏目目录 → 简短互动提示 → 第一款游戏`。目录要帮助跳转，不要把十几个名字逐一念完。

### 句子语法

- 优先使用“动词 + 具体对象 + 可见结果”：`规划流水线，把一座基地压进一张蓝图`。
- 用 2–4 个结构相同的短句形成节奏；一个口播句尽量只对应一个镜头事实。
- 允许少量口语化自问自答和轻微夸张，但下一句必须给实机证据或限制条件。
- 把品类术语翻译成体验：不先说“系统耦合”，先说“种田、开店和采矿会互相抢时间”。
- 保留缺点。发现型推荐不是广告稿，最迟在前 40% 点出一个真实代价。
- 不复制创作者的固定口癖、昵称、自称、语气词密度或性别化人设。

### 正文节奏

正文仍以“核心循环 → 变化/成长 → 最强体验 → 最大门槛 → 适合谁”收束。苏安安样本的可迁移点是把机制解释绑定到玩家行为，不是删掉分析：

- 每个系统先给玩家动作，再给设计判断。
- 每 20–40 秒回答一次“然后呢”：新目标、新奖励、新风险或新组合。
- 列表视频每款游戏都交代四件事：`一句场景、核心动作、一个差异点、当前状态/平台/价格来源`。
- 结论用条件句，不用“无脑冲”“必买”代替适配判断。

## 二、视频：一句一证据，快开场、稳正文

### 镜头规则

- 前 15 秒以 1.5–3 秒为一拍；每个口播短句切到能直接证明它的实机动作。
- 优先展示操作结果、极端状态、成长前后和失败瞬间，不用普通走路或菜单填画面。
- 正文不机械快切。新论点、新系统或新结果出现时换镜头；同一操作需要看清因果时允许停留 4–8 秒。
- 机制较小或 UI 较密时，用裁切、放大、箭头或局部高亮明确观众该看哪里。
- 梗图和反应素材只用于转折或代价，默认每 60–90 秒不超过一次；不能替代实机证据。

### 字幕与信息层

- 主字幕固定在底部安全区，白字、深色描边或黑底，单行优先，最多两行。
- 关键词只高亮动作、数字或结果，不整句变色。
- 月度盘点在 15–25 秒给一次目录卡；每款游戏入场时用统一信息卡显示游戏名、平台和发售状态。
- 保留轻量频道水印即可，不用人物头像长期遮挡实机。

## 三、标题：情绪判断 + 玩法幻想 + 可搜索对象

常见的有效骨架不是某个固定词，而是三段分工：

1. **情绪或反常判断**：`好缝好怪，但还想玩`。
2. **玩家幻想**：`开店暴富`、`美少女搞基建`、`变身种田恋爱`。
3. **搜索锚点**：游戏名、品类、平台、版本或促销节点。

应用时：

- 前 10–14 个字必须能独立表达动作或矛盾。
- 一个标题最多押一个主矛盾；第二段只负责补结果或搜索词。
- 问号适合制造结果缺口，感叹号适合表达已兑现结论；默认合计不超过 2 个。
- 百分比、折扣、史低、版本和“正式版”必须带来源与时间，过期就删。
- 月度/促销盘点可放宽到 32 字，但要把月份、平台和品类放在可扫描位置。

## 四、封面：高密度不等于多中心

样本常用高饱和游戏画面、黄/白粗字黑描边、角色或机制结果做中心，并以游戏名、数字或短标签补证据。迁移时压缩成三级层级：

1. **主视觉**：一个角色、建筑、基地全景或关键操作结果，占画面约 40%–60%。
2. **主文案**：4–8 字，只说一个玩法幻想或矛盾，黄/白粗字配深描边。
3. **证据标签**：最多一个，2–6 字或一个数字，例如“50+ 技巧”“3 折”“正式版”；游戏名作为小标签。

不要同时放两个大标题、多个角色头像、完整 UI 和一排数据。封面缩到原尺寸 10% 后，观众应先读到主文案，再看到主视觉，最后才识别游戏名/证据标签。

## 五、迁移到“李三两Owl”

保留：

- 玩家动作优先于策划术语。
- 前 20 秒高密度兑现标题与封面。
- 口语短句、并列动词和一句一镜头。
- 封面用真实实机、强层级和一个可核验标签。

不要迁移：

- “可爱”“老婆”“美少女”等与游戏或频道受众无关的默认措辞。
- 只夸不评、以情绪代替机制分析。
- 直播切片头像、固定口癖或近似复刻的标题句。
- 为追求快节奏牺牲因果、缺点和购买建议。

默认做法是“苏安安式可进入性 + 李三两Owl 的策划判断”：开场让玩家马上想象自己会做什么，正文解释为什么这个循环成立、在哪里失效、适合谁。
