# Godot Shader 手册（godot-shader）

## 概述

**命令**：`/godot-shader`

Godot 4.X shader 中文手册，整理自 <https://gdbook.kidsgame.top/shader-book/>（肖老师的Godot实验室）。全书 22 章，从 GPU 基础、图形学数学一路讲到 2D/3D 特效：噪声、距离场、屏幕后处理、顶点动画、水体、描边、卡通光照等。适合「会用 Godot 搭场景但每次看到 shader 代码就头大」的开发者。

## 章节结构

| 部分 | 章节 | 内容 |
|------|------|------|
| **基础** | ch01–04 | GPU 概念、图形学数学、坐标空间、shader 骨架 |
| **2D 核心技术** | ch05–11 | 数学函数、塑形、噪声、SDF、纹理、屏幕空间、预处理 |
| **2D 特效实战** | ch12–17 | 顶点动画、HSV 颜色、遮罩（溶解/斗篷）、描边、复古故障、2D 水体 |
| **3D 材质光照** | ch18–22 | 3D 顶点动画、PBR 属性、light() 自定义光照、3D 水体、3D 描边 |

完整 22 章明细见 `SKILL.md` 的快速索引表。

## 使用方法

```
/godot-shader 给角色加个描边效果
/godot-shader 做一个水面 shader，风格化卡通风格
/godot-shader 受伤闪白 + 溶解死亡效果怎么做
```

技能会先按需求定位章节，再读取 `references/chXX.md` 取完整代码和讲解。

## 文件组织

```
godot-shader/
├── SKILL.md              ← 技能指令（AI 读）：索引 + 速查 + 常见坑
├── README.md             ← 本文件（人读）
└── references/
    ├── ch01.md ... ch22.md  ← 各章完整内容（概念 + 代码 + 练习）
```
