## When to invoke this skill

### General triggers

- 用户讨论语言差异、"为什么英/中文这么说"、翻译困难
- User asks about how English/Chinese "thinks differently," untranslatability, or why a text "feels different" across languages
- 涉及学术写作风格、语言与思维关系的讨论
- 用户给了你一段文本（英/中），希望超出表层语法的深入分析

### Mode-specific triggers

**Mode 1 — analyze (文本分析)**:
- "分析这段英文/中文" / "分析这段话的语言特征"
- "what language defaults are operating here"
- "从语言默认值角度分析这段"
- "看看这段话的语法默认值"
- User provides a passage without specifying a mode — default to analyze

**Mode 2 — thaw (名词化解冻)**:
- "名词太多" / "太书面" / "太学术了" / "改成更主动的写法"
- "unfreeze this text" / "thaw this" / "rewrite to show the actors"
- "名词化解冻" / "解冻这段英文"
- "这段英文太绕了，帮我改写"
- A text with heavy -tion/-ment/-ence density needs unwrapping

**Mode 3 — contrast (翻译对照分析)**:
- "对比这段翻译" / "compare translations"
- "translation pair analysis" / "compare Chinese and English"
- "中文和英文的区别" / "为什么中文这样翻译"
- User provides a text in both languages (original + translation)

**Mode 4 — diagnose (L1 干扰诊断)**:
- "中式英语" / "Chinglish" / "中国学生的英语"
- "diagnose this Chinglish" / "Chinese learner's English"
- "L1 interference" / "看这里面的中文英语"
- User provides English text written by a Chinese native speaker

**Mode 5 — explain (概念讲解)**:
- "什么是语法隐喻" / "讲一下话题优先" / "什么是主语强制"
- "explain topic-prominence" / "what is nominalization"
- "讲一讲系动词统一" / "解释一下 grammatical metaphor"
- "what does Li & Thompson say" / "Benveniste 的观点"
- User asks for a definition of a specific concept from the framework

### Do NOT invoke for

- 基础语法纠错（"fix this sentence" without analytical framing）
- 简单翻译请求（只翻不分析）
- 拼写/打字错误修正
- 初级语言学习练习（"teach me English articles"）
- 非自然语言输入（代码、数学公式、数据）

# 语言默认值分析框架

## 定位

这是一个**分析语言认知默认值的元工具**——基于刚老师原文提出的框架：英文和中文在语法层面各有一套"默认值"，它们在说话者开口之前已经预先摆好了世界的模样。本技能不教语法，而是帮你**看见**这些默认值如何在每次开口时运作。

**核心原则**：
- 描述差异，不评价优劣。不说"汉语 lack 英语 has"，说"英语 obligates 汉语 permits"
- 每个主张锚定具体学者，不制造"语言学都市传说"
- "默认值不是牢笼，换得动"——就像怀特海用英语写出过程哲学，汉译佛经把实体论搬进汉语
- 词汇量加的是内容；默认值这一层，从来不出现在任何一张卷子上

## 核心框架：六种语言默认值

按"表层→深层"排列：从最容易被观察到的主语强制，到底层 ontology 层面的系动词统一。

### 1. Subject Obligation / 主语强制

**核心主张**：英语要求每个定式分句都有一个显式主语；汉语常规性地允许无主句。

**英语机制**：陈述句必须有主语。当语义上没有主语时，使用 dummy element（it, there）填位。

```
It's raining.           → it 不指任何东西，但必须在
There is a book.        → there 不指任何东西，但必须在
Mistakes were made.     → 被动语态隐藏施事，但主语位不能空
```

**汉语机制**：话题-评论结构中，主语可以省略。不需要填充物。

```
下雨了。                  → 无主句，自然成立
桌上有本书。              → "有"字存现句，无需填充主语
杯子碎了。                → 只说发生了什么，不追问"谁"
```

**学术依据**：
- Li & Thompson (1976) 将英语归入"主语优先型"语言，汉语归入"话题优先型"语言
- 主语优先语言强制：每个句子必须有一个语法主语，即使它是语义空壳

**哲学含义**（Benveniste 1958 延伸）：
英语在开口前先问"谁"——答不上来也得答。主语强制把每个事件解析为"某个东西做了某个动作"。世界因此预先由施事构成，事情是施事做出来的。汉语允许事件就那么自己发生。

**文本检测特征**：
- Dummy subjects: it, there (It is important that..., There are many...)
- 被动态中主语被保留但施事被删除或后置 (by phrase)
- 英语中找不到自然的主语但为了语法硬加的填充
- 汉语中自然省略的主语在英语中被显式补出

### 2. Article Individualization / 冠词个体化

**核心主张**：英语强制每个名词标记有定/无定和可数/不可数；汉语无冠词，复数标记可选。

**英语机制**：每次使用名词，必须在 a / the / ∅ / 复数 之间做出选择。这使你无法不表态地"提一个东西"。

```
I bought a book.       → 引入新个体
I bought the book.     → 引用已知名册上的个体
I bought books.        → 无定复数，不具体指出哪些
* I bought book.       → 不存在，冠词不能省
```

另：可数/不可数强制。（"a furniture" × "a piece of furniture" √）

**汉语机制**：
"我买了书"——不需指定"一本 / 那本 / 那些"。语境决定数量和有定性。量词系统（个/只/本/条/张）需要在数词后出现，但零标记永远合法。

**the 的关键含义**：
The 的意思是"我们都认得的那一个"。用 the = 宣布某样东西已经在我们的共同名册上。用 a = 往名册上添新的。说英语时你一直在维护这份名册。汉语没有这份名册。

**学术依据**：
英语冠词系统作为语法化的有定/无定标记（Quirk et al. 1985）；汉语量词系统作为不同的个体化策略（Erbaugh 1986）

**哲学含义**：
英语强制说话者不断将世界"切块"并追踪每个所指的身份。边界、数目、身份——这是每样东西的三件行李。世界因此被切成可数的分立个体，而"书"不能是"一团没有边界的书"。

**文本检测特征**：
- 冠词使用模式（a / the / ∅ 的分布）
- 可数/不可数名词区分（furniture/information 在英语中不可数）
- 复数标记的强制出现
- 汉语 bare nouns 在英语中被冠词强制分解
- 前指（anaphoric reference）中的 the 使用

### 3. Externalized Time / 时间外置

**核心主张**：英语在动词上强制标记时态（相对于说话时间的时点）；汉语使用体标记（了/着/过）不标记时态。

**英语机制**：每个限定动词必须有时态。即使上下文已经明确时间（"yesterday"），动词仍然要标记过去时。

```
I bought a book yesterday.   → yesterday 已说明时间，bought 还是必须标过去

I bought a book.             → 过去时，完成事件
I have bought a book.        → 现在完成时，与现在关联
* I buy a book yesterday.    → 不合法，时态必须和时间副词一致
```

**汉语机制**：
"我昨天买了书"——了标记"完成体"，不是过去时。"我昨天买书"也成立，了是可选。
"我买过书"——过标记"经历体"。
"我买着书"——着标记"持续体"。
这些标记均不告诉你是过去、现在还是未来——这个信息来自上下文或语境。

**学术依据**：
时态突出型（tense-prominent）与体突出型（aspect-prominent）语言分类

**哲学含义**：
英语把时间做成了事件之外的独立坐标轴。事件被钉在轴上的某一点。"三天"（three days）在语法上和"三本书"（three books）是同一种东西——可数名词。时间本身也变成了可以拿尺子量的东西。事件不流动，它只是被安置在轴上的某个位置。

**文本检测特征**：
- 每个定式动词的时态标记
- 时态一致性/backshifting（间接引语中的时序关系）
- 英语中时间副词通常与特定时态共现
- 汉语中时间表达依赖语境和体标记（了/着/过），而非动词变形
- 汉语时间词仅在语境不充分时才出现

### 4. Nominalization / Grammatical Metaphor / 名词化与语法隐喻

**核心主张**：英语（尤其学术/专业文体）系统性地将过程（动词）凝固为实体（名词）；汉语学术文体保持较多动词形式。

**英语机制**：过程中→事物的转变通过派生后缀完成。

```
implement         → implementation           (动词 → 名词)
reduce            → reduction                (动词 → 名词)
fail              → failure                  (动词 → 名词)
analyze           → analysis                 (动词 → 名词)
grow              → the growth of X          (过程 → 事物)
develop           → the development of X     (过程 → 事物)
```

典型名词化密集句：

> The implementation of the policy resulted in a reduction in complaints.

→ 11 个词，零个真正在动的动词。implement 和 reduce 都被冻成了名词。

**汉语机制**：
汉语不通过派生后缀把动词变成名词。"实施"仍然是"实施"——可以在动词位也可以在名词位，但词形不变，过程仍活。

> 实施了计划后，投诉减少了。

→ 两个动词，施事隐含，事件在流动。

**学术依据**：
- Halliday (1985) "语法隐喻"概念——系统的"一致式"（动词）→"隐喻式"（名词）替换
- Biber & Gray (2010)：学术英语不把句子拉长，而把它**压扁**——从句（尤其是限定性从句）在会话中比学术论文中更常见。学术英语的反直觉特征：不是"更复杂的中文"，而是"信息被压进了名词短语"

**哲学含义**：
过程一旦变成东西，它就能被拥有（the company's growth）、被比较（a sharper decline）、被写进 KPI（a reduction in complaints）。能动的部分全没了。这是最彻底的"默认值操作"：连唯一可能松动"世界由离散个体组成"这一预设的东西——**变化本身**——也被抓回来，登记成一个可以清点的对象。

**文本检测特征**：
- 高频 -tion/-ment/-ence/-ity/-al/-ure/-sis/-ing 抽象名词
- 长名词短语（the rapid development of...）
- 被动结构 + 名词化组合
- 句子谓语使用弱动词（result in, lead to, cause, have, provide）
- 动词密度低（每句动词数量远少于名词短语数量）

### 5. Topic-Prominence vs Subject-Prominence / 话题优先与主语优先

**核心主张**：汉语按"话题-评论"组织句子，英语按"主语-谓语"组织。这是两种截然不同的句子组织逻辑。

**英语机制（主语优先）**：
句子围绕主语-谓语结构组织。主语通常是施事，谓语描述动作。句子的语法结构同时也是信息结构。

```
I have read this book.
S V         O
主语 = 施事 = 话题（三位一体）
```

**汉语机制（话题优先）**：
句子先立一个"话题"（关于什么），再说"评论"（关于它要说什么）。话题不一定和谓语动词有语法关系。

```
这本书 我看过了。              → 话题 + 评论
T        C
话题（这本书）≠ 主语（我）

那场火，幸亏消防队来得快。    → 话题与谓语动词无语法关系
大象鼻子长。                  → 双主语句，"大象"是话题，"鼻子"是主语
```

**学术依据**：
- Li & Thompson (1976) "Subject and Topic: A New Typology of Language"——这篇论文证明话题优先和主语优先是两种不同的语言类型，不是同一结构的不同名称
- 汉语（普通话）是话题优先型的原型代表
- 英语是典型的主语优先型语言

**哲学含义**：
开口前先问的不是"谁在做"，而是"关于什么"。世界因此默认从情境和关系起手，不从施事起手。这直接影响了中国哲学对"关系而非实体"的关注。汉语的一句话可以一节一节往下走，靠情境接住，不需要把结构焊成一个复合句；英语必须在句子内部交代清楚所有语法关系。

**文本检测特征**：
- 汉语中位于句首但不充当其后动词主语的名词短语
- 双主语句式（NP1 + NP2 + predicate，NP1 是话题 NP2 是主语）
- "关于"/"至于"/"对于"开头的话题标记
- 英语中话题前置但需要重写为 subject-predicate 结构的中式表达
- 汉语允许主语在连续分句中自由切换而不需要连接词

### 6. "be" Verb Convergence / 系动词统一

**核心主张**：英语用一个动词 "be" 覆盖身份、存在、处所、属性、真值等不同逻辑关系；汉语将这些功能分散到不同的词上。

**英语机制：**
be 的 5 个不同功能，共享同一个词根：

```

身份 (Identity):    He is a teacher.          → 他是老师
存在 (Existence):   There is a book.          → 有本书
处所 (Location):    The book is on the desk.  → 书在桌上
属性 (Property):    The book is red.          → 书是红色的 / 书很红
真值 (Truth):       That is true.             → 那是真的
```

一个词做了五件事。这在大多数欧洲语言中类似（希腊语 einai, 法语 être, 德语 sein）。

**汉语机制：**
五个功能对应不同的词/结构：

```

身份 → 是：他是老师
存在 → 有：有本书（不是"是本书"）
处所 → 在：书在桌上（不是"书是桌上"）
属性 → 很/零系词：书很红 / 书红（不是"书是红"）
真值 → 是：那是真的
```

汉语从根上分离了"是""有""在"——三套逻辑，没有融合。

**学术依据**：
- Benveniste (1958) "Catégories de pensée et catégories de langue"：亚里士多德的十个范畴（实体、量、质、关系、处所、时间、姿态、状态、主动、被动）不是对世界本身的划分——它们就是希腊语的句子成分
- Benveniste 的结论："亚里士多德以为自己在给世界分类，分的其实是希腊语的句子成分"
- 汪子嵩与王太庆《关于"存在"和"是"》：希腊哲学能把 being 立成万学之基，前提是希腊语先把这几件事焊进了同一个词；汉语译者面对它时，"是/存在/有"怎么选，两千年后仍在争

**哲学含义**：
这是最深层的默认值。"be" 把存在、身份、属性、处所、真值焊进同一个词，塑造了西方哲学中 "Being" 作为第一概念的传统。巴门尼德的"是的东西就是，不是的东西根本不能被想"——在一门把"是"用得这么重的语言里，这个念头几乎是自己冒出来的。而汉语从一开始就分离了"是/有"，天然拥有"有/无"这对范畴——《老子》"天下万物生于有，有生于无"，在巴门尼德面前不可想象，在汉语里读着毫不费力。

**文本检测特征**：
- 英语 "be" 在不同功能间的分布频率
- "There is/are" 存在结构
- 系动词 + 形容词结构
- 汉语对应的表达中"是"和"有"和"在"的切换
- "be" 在科学/哲学文本中当核心概念词使用时（being, Being, 作为 to be 的名词化）

## 模式操作

### 共享输出规范（所有模式通用）

1. **语言匹配**：用户用中文 → 输出中文；用英文 → 输出英文。中英混合 → 匹配占主导的语言。
2. **术语处理**：首次出现时双语标注——"Subject Obligation (主语强制)"。之后可用单语。
3. **语气**：分析性而非规约性。使用"英语 obligates / 汉语 permits"，不说"英语更好 / 汉语 lacks"。描述差异，不评判优劣。
4. **学术锚定**：每个关键主张锚定具体学者（Benveniste / Li & Thompson / Halliday / Biber）。不说"研究表明……" 而说 "Benveniste (1958) 论证……"。
5. **可及性**：引入术语后紧跟直观解释。先给具体例子，再给标签。避免纯术语堆砌。
6. **适度表述**：说"汉语不把时态语法化到动词上"，不说"汉语没有时间这种范畴"。
7. **深度自适应**：
   - 简短输入（<20 词）或简单问题 → 只展开最活跃的 2-3 个默认值
   - 默认 → 列出所有活跃默认值 + 结构化分析 + 示例 + 关键引用
   - 用户要求"深入分析""详细讲" → 全部 6 个默认值逐一检查 + Benveniste 级哲学含义 + 默认值间交互分析

### Mode 1: analyze — 文本分析

**什么时候进入**：用户给了一段文本（英或中），希望从默认值角度分析。或者未指定模式时，文本分析是默认入口。

**处理流程**：
1. 检测输入语言（中文 / 英文 / 混合）
2. 逐默认值扫描文本中对应的特征标记
3. 选出最活跃的 2-4 个默认值作为分析重点
4. 不要所有默认值等量齐观——只用那些**确实在文本中活跃的**

**输出格式**：

```
## 语言默认值分析

**输入语言**：[English / 中文 / 混合]
**活跃默认值**：[最显著的 2-4 个，按活跃度降序]

### [Default Name / 默认值名称]
该默认值在此文本中：[活跃 / 不活跃]

**证据**：[引用原文中的具体特征]
- [示例 1] → [(特征说明)]
- [示例 2] → [(特征说明)]

**分析**：[这个默认值如何构造了该文本的世界呈现——它在做什么]
**对照**：[另一种语言处理同样内容时这个默认值会怎么运作]

### [Next Default]
...

### 认知轮廓总结

[该文本投射出的核心认知特征——它是"施事驱动"还是"情境驱动"？是"名词化凝固"还是"流动过程"？它的时间框架是外在坐标还是内在轮廓？]
```

**边界情况**：
- 短文本（<10 词）：标注样本有限，分析为初步性质
- 诗歌/创意写作：默认值可能被刻意打破——这是特征不是错误，值得分析
- 技术/学术英语：高名词化是预期行为，不做负面评价
- 代码/数学/非自然语言输入：优雅拒绝——"本技能分析自然语言文本，请提供散文段落"

---

### Mode 2: thaw — 名词化解冻

**什么时候进入**：用户给了名词密集的英文，希望"解冻"——恢复施事、动词化和过程呈现。

**处理流程**：
1. 识别名词化短语（源自动词/形容词的名词：implementation, decision, analysis, failure, improvement 等）
2. 识别缺失的施事（谁实施的？谁决定的？）
3. 识别将过程压缩为实体的长名词短语
4. 追溯语法隐喻链：每个名词化转回动词
5. 重写：恢复施事，动词化名词化表达，让施动关系显式化

**输出格式**：

```
## 名词化解冻

### 原文
[标记了名词化短语的原文]
（标出：**implementation** 型短语，隐藏的施事，弱谓语动词）

### 解冻版本
[恢复施事、动词化的改写文本]
（保持原文含义和文体层次，但让过程流动起来）

### 转换对照表
| 原短语 | 名词化类型 | 还原形式 |
|--------|-----------|---------|
| "the implementation of" | 过程→实体 | "[施事] implemented" |
| "a reduction in" | 过程→实体 | "[施事] reduced" / "[主格] fell" |
| ... | ... | ... |

### 被隐藏了什么
[总结：这轮名词化隐藏了什么？]
- **施事**：谁在做？
- **时间**：什么时候做的？
- **责任**：谁负责？
- **过程感**：它是活的还是已经冻住了？

### 练习建议
把你自己最近写的一段英文拿出来：圈出每个 the -tion、the -ment、the -ing，问它原来是哪个动词。圈得越多，你的英文离名词化越近。这不是文风问题——这是英语默认的世界形状在你笔下自动完成了一次凝固。
```

**边界情况**：
- 输入没有明显名词化 → 说明不需解冻，建议 analyze 模式
- 中文输入 → 说明汉语抵制名词化，解冻模式主要针对英文；建议 contrast 模式做对照分析
- 混合被动/名词化 → 同时处理被动语态和名词化，两者经常共同运作

### Mode 3: contrast — 翻译对照分析

**什么时候进入**：用户提供中英翻译对（或英中互译文本），希望分析两套语言默认值在翻译中的运作。

**处理流程**：
1. 句级对齐两段文本
2. 逐对齐对检测每个默认值的分岔点：
   - 主语：英文添加主语 → 中文无/隐含主语
   - 冠词：英文 a/the → 中文 bare noun
   - 时态：英文过去/现在/将来 → 中文体标记/语境
   - 名词化：英文名词化短语 → 中文动词化表达
   - 话题位置：中文话题前置 → 英文重构为主语-谓语
   - 系动词：英文 be → 中文是/有/在/很切换
3. 选最深层的 1-2 处分岔做深入分析

**输出格式**：

```
## 语言默认值对照

### 对照对
- **中文**：[中文原文]
- **英文**：[英文译文]

### 差异映射表
| 特征 | 中文文本 | 英文文本 | 活跃默认值 |
|------|---------|---------|-----------|
| 主语 | [省略/隐含] | [显式主语] | 主语强制 |
| 冠词 | 无冠词 | [a/the/∅] | 冠词个体化 |
| 时间标记 | [了/着/过/无] | [tense] | 时间外置 |
| 过程表达 | [动词] | [名词化/动词] | 语法隐喻 |
| 句子组织 | [话题-评论] | [主语-谓语] | 话题优先 vs 主语优先 |
| 系动词 | [是/有/在/很] | [be] | 系动词统一 |
| […] | … | … | … |

### 关键差异分析

**最显著的分岔：[X 默认值]**
[引用原文中的具体对照]
[分析：英语/中文各自怎么处理同一意思]
[学术引证]

**第二分岔：[Y 默认值]**
[…]

### 翻译策略说明

[译者在这个对照中做了什么隐式选择？——是遵循目标语言的默认值，还是有意保留了源语言的痕迹？这是好的翻译判断还是可以被讨论的？]
```

**边界情况**：
- 用户只提供单语文本 → 先自动生成对译版本，再基于这个版本做对照分析（标注"此为基于默认值框架生成的推定对译，非人工译文"）
- 专业出版译文 vs 用户自译 → 区分分析深度和语境
- 习语密集文本 → 说明习语翻译对默认值的覆盖/override 效应
- 双语语码混合文本（code-switching）→ 对切换点做重点分析

### Mode 4: diagnose — L1 干扰诊断

**什么时候进入**：用户提供中文母语者写的英文文本，希望诊断中文默认值转移到英文的痕迹。

**处理流程**：
1. 扫描文本，检测中文默认值向英文转移的六种模式：
   - **主语强制转移**：缺主语、滥加 dummy it/there
   - **冠词转移**：漏 a/the、混用可数不可数
   - **时态转移**：时态不一致、体标记误用时态
   - **话题转移**：中文话题前置结构直接搬到英文
   - **名词化转移**：对名词化的躲避或误用
   - **系动词转移**：漏 be、混用 is/has/are
2. 重要：只分析默认值转移类错误，不要变成全面语法纠错
3. 按交际影响排序（哪些最影响理解）

**输出格式**：

```
## L1 干扰诊断

### 标记文本
[标注了默认值转移的原文]

### 各默认值发现

**主语强制转移**
- [发现 1]：[原文示例] → [中文默认值的预测] → [修改建议]
- [发现 2]：[原文示例] → [...]

**冠词个体化转移**
- [...]

**时间外置转移**
- [...]

### 优先级排序
[按交际影响排序：哪些最影响清晰度和可理解性]

### 非框架相关问题
[其他不属于默认值框架的错误——简短列出但不展开。可提一句：不属于本技能分析范围，建议另行校对。]
```

**关键立场**：
这些"错误"不是错误，是母语语法训练了说话者优先关注另一套东西。中文语法从来没有训练过你去检查"这句的主语在不在"。说中文只需要话题，不需要主语。所以中文母语者写英文时漏主语——这根本不是粗心，是你的语法默认值没有为你装备这个检查。

**边界情况**：
- 高水平学习者文本：不应强行套框架——如果默认值转移很少，说明学习者已成功抑制了 L1 默认值
- 初学者大量错误：只筛选默认值相关模式，不要覆盖全部
- 用户要求全面纠错：说明本技能聚焦深层结构转移，建议与其他校对工具配合
- 语气必须尊重源语言：不是"中国人犯 Y 错误"，而是"中文语法训练了说话者优先关注 X，这个优势在切换为英文时带来了迁移成本"

### Mode 5: explain — 概念讲解

**什么时候进入**：用户要求解释框架中的某个具体概念——可能是术语（"语法隐喻""话题优先"）也可能是学者（"Benveniste 说了什么""Li & Thompson 1976"）。

**处理流程**：
1. 识别概念（支持英文/中文名称、学者姓名、模糊描述）
2. 判断所需深度：
   - 简短查询（"what is topic-prominence"）→ 2-3 段 + 示例
   - 详细查询（"详细讲一下 Benveniste 的论证"）→ 完整处理

**输出格式**：

```
## [Concept Name / 概念名称] — 讲解

### 核心思想
[一句话定义。如系多个相关概念集中请求，逐一列出]

### 运作机制
[语言学机制说明——它如何运作、在哪里体现]

### 示例
- **英语**：[示例]
- **汉语**：[示例]
- **对照**：[双语差异展示]

### 为什么重要
[哲学含义——这个默认值如何塑造了使用者的认知注意力和世界观]

### 学术脉络
- [学者 1] ([年份])：[关键发现]
- [学者 2] ([年份])：[关键发现]

### 相关概念
- [其他默认值 1]：[与本概念互动的方式]
- [其他默认值 2]：[互动方式]
```

**边界情况**：
- 概念不在 6 个默认值框架中 → 诚实说明，提供最接近的相关概念
- 模糊描述（"那个语言决定思维的理论"）→ 澄清后给出精确概念
- 请求语言学中与本框架无关的概念（"讲一下音系学"）→ 优雅重定向
- 用户要求对比两个概念 → 激活 contrast 式分析

## 质量边界

### 本技能做

- 通过 6 个默认值镜头分析英中文本
- 提供基于语言学研究的结构化、可引用分析
- 让不可见的语法默认值对非语言学者可见
- 揭示翻译中两套默认值的张力
- 帮助中文母语者理解自己的英文写作中深层结构的来源

### 本技能不做

- **不做语法检查器**：不改逗号、主谓一致、拼写
- **不做翻译工具**：分析翻译但不主动生成翻译（除非 contrast 模式中需要生成推定对译）
- **不做语言教师**：不教 ESL/CSL 基础课程
- **不做强 Whorfian 框架**：不说"语言决定思维"——说的是语法义务塑造注意力方向，不是锁死认知
- **不做通用框架**：6 个默认值是英中对照特化的，不适用于所有语言对
- **不做规约判断**：不说哪门语言的默认值"正确"——只画地图，不做审判
- **不处理非自然语言**：代码、数学公式、数据等内容优雅拒绝

### 完成检查清单

- [ ] 输入语言正确识别
- [ ] 输出匹配用户语言
- [ ] 每个主张对应到具体默认值，不是泛泛之谈
- [ ] 示例真实且有说明力（不制造稻草人）
- [ ] 语气分析性而非评价性
- [ ] 哲学主张有署名引用（Benveniste / Halliday 等）
- [ ] 边界情况已处理：空输入、短文本、非语言内容、基础语法问题
- [ ] 输出结构化、分段清晰、可扫读
- [ ] 如需深入分析但输入信息不足，已明确标注"信息不足以确认，需补充"

## References

Benveniste, É. (1958). "Catégories de pensée et catégories de langue." *Les Études philosophiques*, 13(4), 419–429.
- 核心论点：亚里士多德的范畴表不是对世界的分类，而是希腊语的句子成分的投影。英语（如同希腊语）将"是/在/真"焊进同一个词 be，塑造了西方哲学将 Being 作为第一概念的传统。

Biber, D., & Gray, B. (2010). "Challenging stereotypes about academic writing: Complexity, elaboration, explicitness." *Journal of English for Academic Purposes*, 9(1), 2–20.
- 语料库发现：学术英语不把句子拉长，而把它压扁——从句在日常会话中比学术论文中更常见。学术英语的信息压缩通过名词短语实现，而非从句嵌套。

Halliday, M.A.K. (1985/1994). *An Introduction to Functional Grammar.* Edward Arnold.
- "语法隐喻"概念的来源：语言从"一致式"（动词驱动）向"隐喻式"（名词驱动）的系统性转移。成长变成增长，实施变成落实，过程变成事物。

Li, C.N., & Thompson, S.A. (1976). "Subject and Topic: A New Typology of Language." In C.N. Li (Ed.), *Subject and Topic* (pp. 457–489). Academic Press.
- 将汉语归入"话题优先型"语言、英语归入"主语优先型"语言的奠基性类型学工作。两个类型遵循截然不同的句子组织逻辑，不是同一结构的不同变体。

汪子嵩、王太庆 (2000). "关于'存在'和'是'." *复旦学报（社会科学版）*, (1).
- 梳理了希腊哲学中 being 概念通过汉语翻译时的"是/存在/有"选择困境，印证了 Benveniste 的跨语言范畴差异论点。

Papafragou, A., Hulbert, J., & Trueswell, J. (2008). "Does language guide event perception? Evidence from eye movements." *Cognition*, 108(1), 155–184.
- 实验证据：只是看着的时候，母语几乎不影响你注意到什么；一旦准备开口，注意力立刻分岔，各自扑向自己那门语言非说不可的部分。语法先改变的，是你准备开口时最先去看哪里。
