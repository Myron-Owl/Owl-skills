# 游戏视频平台封面构图与验收

## 先判断平台

同一套选题可以复用视觉识别，但不能复用已经排好文字的成品构图。先回到原始实机帧，再为平台重新裁切、放大和排版。

| 平台 | 默认画布 | 额外预览 | 构图重点 |
| --- | --- | --- | --- |
| B 站 / YouTube | 1920×1080，16:9 | 原尺寸 10% 缩略图 | 横向分配主文案与主视觉，保证单一阅读顺序 |
| 抖音 | 1080×1920，9:16 | 中心 3:4 裁切 + 原尺寸 10% 缩略图 | 大字在上、实机主体居中、底部留 UI 风险区 |

平台展示规则会变化。中心 3:4 是兼容性预览，不把它表述成永久不变的平台规范；交付前仍应以当前客户端的实际预览为准。

## 保护真实游戏内容

1. 最终底图只用实机截图、官方素材或用户已授权素材。
2. 允许确定性裁切、缩放、调色、暗角、描边、箭头和排版；不要重画角色、敌人、地砖、卡片、数字或 UI。
3. 生成式图片最多用于构图探索。逐项对比角色数量、位置、地砖、指示箭头、卡牌和 UI；任一项被改变，就弃用生成稿，不能把它当成成品。
4. 保留原始素材和既有平台封面，新增平台版本使用独立文件名，禁止覆盖。

## 抖音 9:16 重构方法

不要把带字的 16:9 封面直接裁成 9:16。横版常把文字和主体分置左右，直接裁切会丢掉其中一个中心。应从同一张原始实机帧重新完成以下步骤：

1. 先定唯一焦点：优先选择一个动作结果、包围局面、奖励揭晓或极端状态，让它占画面约 40%–60%。
2. 用 `object-fit: cover` 或等价裁切把焦点移到竖屏中部；需要时放大，但不要把关键敌人、数字或动作结果裁掉。
3. 主文案放在画面上部约 15%–40%，优先两行，每行 3–6 个汉字；暖白/亮色填充配深色粗描边，手机缩略图先读字形而不是装饰。
4. 主视觉放在约 40%–78%，避免标题遮住动作结果。
5. 游戏名和最多一句机制补充放在中心 3:4 的下边界以内；最底部约 15% 不放关键信息，避免界面、说明文字或裁切遮挡。
6. 重要信息总层级不超过三层：主文案 → 主视觉 → 游戏名/一个证据标签。删掉不能改变点击判断的装饰性标签。

### 中心 3:4 兼容区

对 `1080×1920` 画布，中心 3:4 预览为 `1080×1440`，纵向范围是 `y=240..1680`。主文案、主视觉核心、游戏名都应在这个区域内保持完整。

通用计算：

```text
crop_height = width × 4 / 3
crop_y = (height - crop_height) / 2
```

## 横版构图

- 16:9 默认使用 `1920×1080`。
- 主视觉占画面约 40%–60%；主文案通常放在另一侧或上方，避免压住玩法证据。
- 主文案 4–8 字，只说一个玩法幻想或矛盾；游戏名使用小标签。
- 横版同样使用真实实机，不用 AI 假画面填补被裁掉的区域。

## 确定性生成

推荐用 HTML/CSS 排版，再用 Playwright 或 HyperFrames 截图：

- 图片元素引用原始实机帧。
- 用固定像素画布、固定字体、固定色值和固定位置；不要使用随机数或异步布局。
- 允许 `saturate`、`contrast`、`brightness`、渐变暗角等不改变玩法事实的处理。
- 横竖版分别维护源文件，例如 `cover-bilibili.html`、`cover-douyin.html`。
- 输出使用可辨认的平台后缀，例如 `<游戏名>_B站封面.png`、`<游戏名>_抖音封面.png`。

## 双预览验收

每张封面至少做一次 10% 缩略图。抖音竖版再做一次中心 3:4 裁切。两张检查图都只用于验收，不替代原尺寸交付物。

抖音 `1080×1920` 示例：

```bash
ffmpeg -y -i cover.png -vf "scale=108:192" -frames:v 1 -update 1 cover-10pct.png
ffmpeg -y -i cover.png -vf "crop=1080:1440:0:240" -frames:v 1 -update 1 cover-center-3x4.png
```

逐项检查：

1. 10% 图中，主文案能否立即读出，焦点是否仍像一个具体游戏局面。
2. 中心 3:4 图中，主文案、焦点和游戏名是否完整，没有刚好贴边。
3. 标题与封面是否分工：标题提出矛盾或判断，封面给出机制、结果或场景，不逐字复读。
4. 实机中的角色数量、位置、UI、数字和箭头是否与原始截图一致。
5. 文件尺寸、分辨率和命名是否正确；既有横版封面是否仍然存在。
