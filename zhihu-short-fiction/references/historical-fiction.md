# 历史语境与小说真实性

由用户提供的“历史学家智能体人格”提炼，并参考现有历史核查方法。用于历史题材、具有明确年代的近现代故事，以及借用历史制度或物质条件的架空小说。目标是让时代条件进入人物的机会、阻力、选择和代价，而不是把正文写成资料汇编。

## 使用索引

- 设定坐标：时间、地点、社会位置和虚构边界。
- 史学视角：日常生活、长时段、微观史、后殖民与比较方法。
- 来源与判断：资料类型、主张性质、学界状态、置信度和核查状态。
- 一致性：物质基础、制度与观念、技术传播、隐蔽时代错误。
- 创作转化：感官细节、桥段因果、叙述视角与历史时间线。
- 架空与反事实：分歧点、保留条件、连锁后果。
- 交付：时期真实性报告与主张核查表。

## 1. 先确定坐标与真实性约定

记录 `时段/具体年份｜地域及当时行政与交通关系｜城乡环境｜季节｜人物身份、阶层与可用资源｜写实程度`。只写“古代”“中世纪”不足以判断细节；先缩小到足以解释当前冲突的范围。纪年换算、历法、地名与行政归属需要实际核验，不能把现代国界倒投回去。

区分三类约定：

- **真实历史背景**：主要事件和制度依证据处理；原创人物、对话与未被记载的生活片段可创作，但不能把杜撰言行说成有记载的史实。
- **受历史启发的架空**：明确哪些地区、时期和制度提供参照，哪些被重组或改写；实际采用的规则须相互一致。
- **反事实历史**：标明从何处偏离既有历史、保留哪些条件，以及改变经过何种机制扩散。

坐标不足时可先标候选并处理不依赖它的部分；若时代选择会改变继承、婚姻、身份或战争等核心情节，先确定这一选择再落实相关规则。核查记录中的置信度和来源放在分析或附注中，不逐句插入小说正文。

## 2. 按问题选用史学视角

| 视角 | 能帮助解决的创作问题 | 使用边界 |
|---|---|---|
| 年鉴学派的跨学科社会史视角 | 从生计、环境、交易、家庭、信仰和生活节奏理解人物处境，补足只写君王与战争的盲区 | 年鉴学派内部方法多样，不等于一张固定的日常物品清单 |
| 布罗代尔式长时段分析 | 区分变化缓慢的地理与生计结构、中期经济社会变化和短期事件；判断一次政变或发明能改变什么 | 长期结构不是命运，不能抹掉个人行动、政治选择和偶然性 |
| 微观史，如金兹堡式个案研究 | 从契约、诉讼、账簿或个人遭遇观察宏观制度如何进入生活 | 一个人或村庄不能自动代表整个时代，必须说明个案的可推广范围 |
| 后殖民史学与底层研究视角 | 检查殖民者、国家或精英档案如何塑造描述，寻找当地知识、口述传统及被遮蔽的行动者 | 发现资料偏向不等于反向叙述自动正确；不能以纠偏为由补造证词 |
| 物质文化与考古方法 | 结合器物、建筑、遗存、环境证据及文字材料，重建实际使用条件 | 存世物受保存与发掘偏差影响；精英墓葬、礼仪文本不能直接代表普通生活 |
| 比较历史学 | 比较不同社会如何解决征税、运输、信贷、照护、继承等相似问题，拓展设定选择 | 对齐时段、地域、规模及功能，不以同名官职或单项技术作文明整体排名 |

优先让题材所在社会自身的纪年、概念和资料传统进入分析；按问题纳入相关非西方视角，不把欧洲经验当作所有地区的默认发展路径，也不为凑地域数量硬加无关案例。

## 3. 把来源与可信程度分开

### 五项记录不能互相替代

| 项目 | 可用标记 | 含义 |
|---|---|---|
| 资料类型 | 一手文字 / 考古或实物 / 口述材料 / 学术研究或综述 / 通俗转述 | 说明证据如何形成；影视和网络碎片主要用于发现线索 |
| 主张性质 | 有据事实 / 合理推断 / 作者设定 / 未知 | 区分材料支持的结论和创作补充 |
| 学界状态 | 有广泛共识 / 存在争论 / 尚无法判断 | 关于研究分歧的判断本身也需来源；“查到一本书”不能证明共识 |
| 置信度 | 高 / 中 / 低，附理由 | 针对这条具体主张的证据支持程度，不是资料名气评分 |
| 核查状态 | 已核原文或原物记录 / 已核转引 / 待核 | 明确实际看过什么；转载数量不等于独立印证 |

高置信度通常需要贴合时地和群体的证据、可靠校勘或研究支持，并能解释相关反证；中置信度可来自可信但单一、间接或有适用范围限制的材料；低置信度表示关键链条缺失或只能类推。合理推断即使很可信，也不能改标成有据事实。作者设定评价的是一致性，不伪装成“史实高置信度”。

一手材料记录了当时或接近当时的说法、行为或遗存，仍须检查作者目的、受众、距离事件的时间、保存与抄传、译文、编辑及选择偏差。法律条文不等于实际执行，宣传不等于事实，亲历也可能误认。可靠的学术综述可能比未经批判的一手材料更适合回答总体问题；不机械采用“一手永远高于二手”的排序。

### 核查顺序与来源边界

1. 先查决定情节能否成立的主张，如谁有权继承、谁能取得证据、旅程能否按时完成、某项技术能否被该人物使用；再查支撑现场的饮食、服饰、称呼等细节。
2. 用相关学术研究定位争议和原始材料，按需回查档案、古籍校注、考古报告、博物馆记录或口述资料。对关键结论争取独立来源相互检验；多篇转述同一材料只算同一证据链。
3. 每条对外输出的史实判断附资料类型、来源位置、置信度与理由。同一依据支持一组细节时可合并列注，但应明确覆盖范围。来源记录作者、题名、版本/年代以及能定位的页码、章节、档号或链接；缺失信息写待核，不补造。
4. 未实际查证的内容保持待核。无法访问原文时明确采用了谁的转引及其限制；资料不足表示未知，不能直接判作不存在，也不能由“可能合理”升级为已证实。
5. 不把提示词里的例句自动当知识库事实。“某文明整体更先进”“某国属于史上最富有”“军人口粮精确到克”等陈述，必须限定领域、指标、时段、对象和证据；未经核查不作为固定事实收入设定。

只有历史核查确有需要时才检索；使用当前可用的检索、档案或本地资料工具。不得声称查过未读取的文献，也不要求为了写一处普通动作而完成全时代调查。原始资料保持原样，摘录与创作推断分别记录。

## 4. 检查时代系统是否相容

先从会限制当前行动的物质条件入手，再与制度、信仰和政治选择相互核对；它们存在双向作用，不把经济或技术当作唯一原因。

| 层面 | 核查问题 | 对人物与桥段的影响 |
|---|---|---|
| 饮食与生计 | 作物、产地、时令、保存、燃料、水源、劳动投入及阶层差异 | 旅途补给、等待期限、疾病风险与家庭负担 |
| 服饰与身体 | 材料、制作成本、修补方式、身份标记、活动限制 | 伪装可否成立、谁认得出身份、逃跑与劳动的难度 |
| 建筑与居住 | 当地材料、照明、门窗、取暖、排水和空间共享 | 隐私、窃听、火灾、藏匿与相遇机会 |
| 交易与财富 | 实际支付手段、度量衡、信用、税费、市场接入及交易成本 | 债务、控制权、经营、赎买与离开关系的条件 |
| 技术与交通通信 | 发明、传入、普及和个人可及性分别到哪一步；维护、原料与人员是否具备 | 证据如何传递、消息何时抵达、力量为何无法即时到场 |
| 权力与法律 | 授权与合法性、财产权、诉讼、成文法、习惯及实际执行 | 谁能裁决、谁能出庭、证据交给谁才有用 |
| 社会关系 | 阶层、亲属、职业、性别、年龄与当地流动渠道 | 谁能结盟、拒绝、迁移、继承，代价由谁承担 |
| 信仰与观念 | 官方教义、地方实践、仪式、禁忌、神话与群体差异 | 人物如何解释危险、履约、求助和正当化选择 |

识别两类时代错误：物件、技术、称谓或制度尚未在该地出现；以及事物虽存在，但这个阶层的人无法取得、不会按这种方式使用，或被赋予不合当地语境的权利与观念。还要检查不同世纪、地域和阶层的细节是否被拼成一个不可能同时存在的场景。

现代小说语言可以帮助阅读，不要求全员仿古说话；需核查的是关键概念、动机、知识与行为条件。人物可以有异于同时代主流的主张，但要呈现其形成途径、可用表达、支持者和社会成本。不以今天的概念直接替代当时处境，也不以“当时如此”淡化暴力与伤害。

神话、传说和口述传统可作为信仰、身份、记忆与政治表达的证据；记录版本、流传群体、采录年代和使用场合。它们既不自动证明所述事件发生，也不能简单当作毫无价值的“错误史实”。

## 5. 让核查结果进入叙事

每个采用的细节都回答：**谁在此时此地能接触它，它怎样改变行动、关系、风险、信息或阅读体验？** 将宏观条件落到微观选择：运输条件改变等待时间，继承规则改变可争夺资源，劳动分工改变谁能够在场。感官细节从材料、工艺和使用环境推导；精确声音、气味或对话若属重建，不能假称史料原样记载。

按场景需要选择少量有效细节，通过使用、缺乏、交易、误认或修补呈现。可以承担安定、亲密、劳累与不便的体验，不要求每件物品都成为伏笔。避免把稀有贵重物或礼仪场景当作全社会常态。

与现有流程合并：

- **故事时间与讲述次序**：复用 [叙事学诊断](narrative-analysis.md) 的区分；倒叙、叙述者误解与史实错误分别判断。人物可以相信当时流行的错误解释，不代表作者应把它写成已经证实的真相。
- **欲望账**：加入人物在该制度、资源和关系中的实际行动空间。
- **信息账**：同时追踪人物能知道什么、消息如何抵达，以及作者哪些时代主张已核查。人物不知道、史料没有记录、作者尚未查证是三种不同情况。
- **兑现账与桥段**：历史条件若决定破案、资格争夺或规则反制，须提前建立适用规则与执行者，不能高潮时临时拿考据当解围工具。
- **持续时间线**：在已有故事笔记中记录事件、制度、物品传播、人物年龄、移动与消息延迟，附参照来源、核查状态和有意偏离。仅维护当前对话或授权项目，不另建无关永久记忆。

新细节与已定设定冲突时，先区分史料分歧、作者有意改写和实际疏漏，再给出保留剧情所需的最小调整；若修正会改变核心故事承诺，说明影响并交由用户选择。

## 6. 架空与反事实

用 `历史参照｜分歧点｜仍保留的条件｜变化机制｜直接后果｜后续限制｜不确定性` 推演。技术提前出现，还要解释知识、能源、材料、劳动力、融资、运输、需求与制度支持中哪些条件已改变。政治结果不能只由一件新武器或一个穿越者的知识自动推出。

给出有条件的可能路径，不称作“必然发生的真实历史”。跨文化借用按实际功能及依赖条件比较，并标明重组之处；架空不要求逐项还原某个真实朝代，但既定世界规则仍须一致。

## 7. 按需交付

**时期真实性报告**：设定坐标与虚构约定；影响剧情的主要发现；物质文化与社会结构；时代错误及证据；相关迷思与争议；可用的日常细节及推断边界；待核项。只展开本稿涉及的部分，每条史实结论标资料类型和置信度。

**历史一致性核查表**：

`主张及稿件位置｜时地与群体｜判定｜证据与资料类型｜学界状态｜置信度及理由｜核查状态｜替代细节/剧情影响｜有意偏离及历史类比`

判定可为准确、部分准确、时代错置、证据不足或有意架空；“常见迷思”需有可追溯的反证，不能把争论直接判成错误。

**创作交付**：正文保持叙事连贯，必要的史实说明、推断和设定偏离另列简短附注。没有完成核查时，说明具体缺口和受影响的结论；不能声称“历史完全准确”。
